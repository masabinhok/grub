Put it on your profile

GRUB needs to live in a repo of your own — that is what makes the numbers real rather than something a website could fake. These five steps do it. Each button opens GitHub with the form already filled in.

  1. Create your copy of the repo

    Opens GitHub's "new repository from template" form with the owner and name filled in. Leave it public — GitHub will not serve images out of a private repo, so your profile would show broken icons instead of a creature.

  2. Let the Action write to it

    Scroll to the bottom. Under Workflow permissions, choose Read and write permissions and save. The job regenerates the cards and commits them back; without this it runs perfectly and then fails on the last line with a 403.

  3. Make it yours

    Run the Adopt this GRUB workflow and paste these three values into its boxes. A fresh copy still carries the previous owner's cached profile, streak and stack; this clears them. Skip it and your cards will show somebody else's name.

    Pet name
    GRUB
    Timezone
    Asia/Kathmandu
    Stack
    —

  4. Feed it once

    Run Tamagotchi of Shame with every input left blank — blank means a real run. Fifteen seconds later your repo holds eleven freshly rendered cards with your own numbers on them. Wait for this to go green before the last step.

  5. Paste it onto your profile

    A public repo named exactly the same as your username shows its README at the top of your profile. Create it, then paste the markdown below. If you already have one, just paste.
