# 🪦 The Wall of Shame

Every GRUB running in public, ranked by **deaths survived** — the one number in
this project that never resets.

A high rank is not a good thing. It means you let it die that many times, and
each one of those is a commit in your history that says `i'm sorry`.

<!-- wall:end -->

> The table between those markers is generated by `scripts/render_wall.js` on
> every daily run. Editing it by hand works exactly as well as editing the README
> caption does, which is to say not at all.

The states are read live from each fork's `pet-state.json`, which is a public file
in every one of these repos — no API token, no backend, no third-party service.
A fork that has gone private, been deleted, or renamed its default branch shows
`⬛ unreachable` until it is fixed or removed.

Everyone else's row is as current as their own last run. This repo's row is read
straight off disk instead of over the network, because fetching it would always
be one run stale — the table is built before the daily job commits the new state,
and the raw file stays cached for minutes after that.

## Get on the wall

You need a GRUB of your own first — [five minutes, no build step](./docs/setup.md).

Then open a PR adding one entry to [`wall-of-shame.json`](./wall-of-shame.json):

```json
{
  "user": "your-github-login",
  "repo": "the-repo-your-grub-lives-in",
  "petName": "WHATEVER YOU RENAMED IT TO",
  "note": "one dry line, 60 characters"
}
```

| Field | Required | Notes |
| --- | --- | --- |
| `user` | yes | Your GitHub login. Must be a real one — it is validated. |
| `repo` | yes | The repo holding `pet-state.json`, not necessarily your profile repo. |
| `petName` | no | Defaults to `GRUB`. 24 characters. |
| `branch` | no | Defaults to `main`, falling back to `master`. Set it if yours is neither. |
| `note` | no | 60 characters, letters and basic punctuation only. Keep it dry. |

Add your entry at the end of the list; the script sorts the table itself, so
where you put it in the file makes no difference. Don't edit the generated table
in this page — regenerate it instead:

```bash
node scripts/render_wall.js --dry-run   # see what it would produce
node scripts/render_wall.js             # rewrite the table
```

Rules, such as they are:

- **One entry per person.** Duplicates are dropped with a warning.
- **The repo has to be public**, or the wall can't read its state and you'll sit
  at `⬛ unreachable` forever.
- **`petName` and `note` are stripped** to letters, numbers and basic
  punctuation before they are written into this page. Anything cleverer than
  that will simply disappear.
- **Ask to be removed any time** — open an issue whose title does *not* start
  with `feed` or `pet` (those get eaten by the feeding workflow) and it comes
  off.
