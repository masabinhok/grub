## whoami

Engineering student at **IOE, Pulchowk Campus** in Kathmandu, mostly writing
TypeScript and mostly thinking about authentication. I like tools that remove a
boring afternoon from someone else's week — a CLI that scaffolds the auth layer
you were about to hand-roll, a boilerplate that already got the refresh-token
rotation right.

Currently: NestJS, Go, and a small pixel creature that publicly starves when I
stop committing.
